What you want	Command
List databases	\l
Connect to database	\c database_name
Show current database	SELECT current_database();
List tables	\dt
List tables in all schemas	\dt *.*
Describe table	\d table_name
Show table data	SELECT * FROM table_name;
Delete table	DROP TABLE table_name;
Delete database	DROP DATABASE database_name;
Exit PostgreSQL	\q

Start Psql:- brew services list

Example of table creation :- 
CREATE TABLE students (
    student_id INTEGER PRIMARY KEY,
    student_name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE,
    age INTEGER CHECK (age >= 16),
    gpa DECIMAL(3,2) CHECK (gpa >= 0 AND gpa <= 4)
);
